# Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my background, skills, projects, and professional interests as an aspiring Game Designer and Computer Science student.

## Overview

This portfolio serves as a central hub for my projects, technical skills, and contact information. It highlights my experience in game development, web development, programming, and problem-solving while providing an easy way for recruiters, collaborators, and peers to connect with me.

## Features

- Responsive and modern user interface
- Personal profile and introduction section
- Portfolio projects showcase
- Programming languages and technical skills
- Soft skills and professional competencies
- Systems and software proficiency
- Social media and professional links
- Contact section for networking opportunities
- Clean navigation with single-page experience

## Installation

1. Clone the repository:

```bash
git clone https://github.com/jfsumu/portfolio.git
```

2. Navigate to the project directory:

```bash
cd portfolio
```

3. Open `index.html` in your browser.
